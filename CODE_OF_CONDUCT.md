# Code of conduct

We want Tactics Journal Board to be a useful place for people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and direct.
- Assume good faith, then focus on the technical issue.
- Welcome useful corrections and questions.
- Keep criticism about the work, not the person.
- Protect private information and unpublished security reports.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks, doxxing, deliberate disruption, and publishing private information without permission are not acceptable.

## Enforcement

Ask a maintainer to address a conduct concern privately through GitHub. Do not use a public issue for a personal report. Security reports belong in [GitHub Security Advisories](https://github.com/TacticsJournal/board/security/advisories/new).

Maintainers may remove comments, close discussions, or restrict participation when needed to keep the project safe and useful.
