# Support

Start with the [README](README.md), [self-hosting guide](docs/self-hosting.md), and [configuration guide](docs/configuration.md).

For a reproducible bug, open the [bug report form](https://github.com/TacticsJournal/board/issues/new?template=bug_report.yml). Include the version, browser and operating system, exact steps, expected result, actual result, and relevant console or test output. Remove private data before posting.

For a feature idea or documentation fix, use the [feature request form](https://github.com/TacticsJournal/board/issues/new?template=feature_request.yml).

Do not report security vulnerabilities in public issues. Use [GitHub Security Advisories](https://github.com/TacticsJournal/board/security/advisories/new) as described in [SECURITY.md](SECURITY.md).
