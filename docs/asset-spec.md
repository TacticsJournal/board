# Asset Spec

Initial target asset list:

- Pitch/tactics board graphic: SVG preferred.
- Home player dot: SVG preferred.
- Away player dot: SVG preferred.
- Neutral/player unknown dot: SVG preferred.
- Ball: SVG or transparent PNG.
- Arrow head or full arrow style: SVG preferred.
- Example match screenshots: PNG/JPG/WebP.

For best editor behavior:

- Keep SVGs centered around their visible shape when possible.
- Avoid huge transparent padding in PNGs.
- Use transparent backgrounds for dots, ball, and arrows.
- If there are multiple board styles, name them clearly: `green-pitch.svg`, `dark-pitch.svg`, etc.
