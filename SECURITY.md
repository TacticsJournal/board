# Security policy

Report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/TacticsJournal/board/security/advisories/new). Do not put credentials, exploit details, or private user data in a public issue or pull request.

Please include the affected version or commit, the affected URL or file, reproduction steps, and the impact. The maintainers will use the advisory to coordinate a fix and disclosure.

The hosted app is at <https://board.tacticsjournal.com>. A self-hosted deployment is operated by its owner, so report deployment-specific problems to that operator as well.

For ordinary bugs and feature requests, use the public issue forms instead. See [SUPPORT.md](SUPPORT.md).
